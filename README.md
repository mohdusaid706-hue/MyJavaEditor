# MyJavaEditor

MyJavaEditor is a lightweight Java text editor and mini IDE built using Java Swing. It allows you to write, edit, compile, and run Java programs
all in one window. Ideal for beginners and for learning how basic IDEs work.  

---

 Features

  New, Open, Save, Save As…– Standard file operations.  
- Cut, Copy, Paste, Delete, Select All – Full text editing features.  
- Time & Date – Insert current date and time.  
- Change Text Color– Customize your editor's text color.  
- Compile Java Programs – Compile `.java` files directly.  
- Run Java Programs – Execute compiled Java files without leaving the editor.  
- Output Console – View compile errors or program output.  



How to Use
javac Editor2015.java
java Editor2015
